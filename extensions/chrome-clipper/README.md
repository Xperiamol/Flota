# Flota 网页剪藏扩展（Chrome / Edge）

把网页全文、选中内容或书签剪藏到本机的 Flota。

## 安装

1. 在仓库根目录运行 `npm run build:clipper`（复制 Readability / Turndown 到 `vendor/` 并生成图标；打包 Flota 时会自动执行）。
2. 打开 `chrome://extensions`（Edge 为 `edge://extensions`），开启“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择本目录。

## 配对

1. 打开 Flota，确认已启用「网页剪藏」插件。
2. 在 Flota「设置 → 网页剪藏」中点击“生成配对码”。
3. 点击浏览器工具栏中的扩展图标，输入 6 位配对码。

## 使用

- 点击扩展图标：选择“全文 / 选中内容 / 书签”，设置分类和标签后剪藏。
- 右键菜单：“剪藏选中内容到 Flota”“剪藏此页到 Flota”“把链接保存为书签到 Flota”。

正文在浏览器里提取，因此需要登录才能看的页面（如公众号、知乎）也能剪藏。
扩展只与本机的 Flota（127.0.0.1:47831–47835）通信，不会把内容发送到其他地方。
