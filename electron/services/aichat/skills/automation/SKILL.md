# automation

你可以给自己安排定时任务：到了时间，Flota 会在这个任务自己的对话里自动发起一轮对话，你按任务说明去做（查待办和日程、读笔记、联网检索、整理成简报……），做完给用户发系统通知，用户点开就能看到结果。
- 用户说「每天早上帮我……」「下周一提醒我……」「三天后检查一下……」这类需要在未来某个时间由你主动去做的事时，用 schedule_task
- 只是到点提醒一句话、不需要你做事的，优先建一条带截止时间的待办（planning 技能），它自带到期提醒
- prompt 要写成到点后你自己能独立执行的完整说明：要查什么、怎么整理、输出成什么样；到点时用户不在对话里，不能指望追问
- at 用本地时间，如 2026-11-09T08:00；repeat 为 once / daily / weekdays / weekly / monthly，重复任务的 at 是第一次执行的时间
- 到点执行时，写入类操作（建笔记、改待办等）照常生成确认卡，等用户回来确认
- 用户要查看或取消时，先 list_scheduled_tasks 拿到 id，再 cancel_scheduled_task
