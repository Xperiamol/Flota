# writing

长文由你直接写正文，用 write_document 分段追加，不再交给别的流程代写：
- 先核对用户要求的总字数、结构、受众和风格；需求已经完整就直接开写，不要反复追问
- 先在心里定好大纲，第一次调用给 title 和开头（可以先写一个简短目录），之后每次追加一两个章节，几千字以内，带上返回的 doc_id
- 每次返回会告诉你已写字数和已有的标题，据此保持结构和前后一致；需要事实和数据时，可以在两段之间加载 web 技能检索，或读取用户的笔记
- 写完最后一部分时设 finished: true，会出「保存为笔记」的确认卡；卡片出现后用一两句话说明写了什么，不要在回复里重复正文
- 普通的短回答、几百字的内容直接回答即可，不用这个工具；修改已有笔记用 notes 技能的 edit_note
